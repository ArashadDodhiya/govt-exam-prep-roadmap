# STEP 1 — FOUNDATION (Zero-Level Introduction)


## What is Algebra?

**Algebra** is the branch of mathematics that uses **letters (variables)** to represent numbers, allowing us to form **equations** and find **unknown values**.

> If 3 chocolates cost ₹45, what does 1 chocolate cost?
> 3x = 45 → x = 15.
> That's algebra — using a letter to find the unknown.

### Why Algebra?

| Concept | What It Does |
|---|---|
| **Variables** | Letters (x, y, z) that stand for unknown numbers |
| **Equations** | Mathematical statements with "=" sign |
| **Identities** | Equations true for ALL values of the variable |
| **Expressions** | Combinations of numbers, variables, and operations |
| **Polynomials** | Expressions with variables raised to whole-number powers |

### The Core Building Blocks

| Term | Meaning | Example |
|---|---|---|
| **Constant** | A fixed number | 5, −3, π |
| **Variable** | A letter representing an unknown | x, y, a |
| **Coefficient** | Number multiplied with a variable | In 3x, coefficient = 3 |
| **Term** | A single piece of an expression | 3x², −5y, 7 |
| **Expression** | Combination of terms | 3x² + 5x − 7 |
| **Equation** | Expression = Expression | 3x + 5 = 20 |

## Why do exams LOVE this topic?

| Reason | Explanation |
|---|---|
| **3–5 questions per paper** | SSC Tier-I and Tier-II both test algebra heavily |
| **Foundation of higher math** | Geometry, Trigonometry, Mensuration all use algebraic methods |
| **Identity-based shortcuts** | Algebraic identities save massive time |
| **Quadratic equations** | A favourite exam topic — roots, nature, sum/product |
| **Connects to everything** | Percentage, Profit/Loss, Interest — all are algebra underneath |

# STEP 3 — CORE CONCEPTS (Logical Order)


---

## CONCEPT 1: Linear Equations in 1 Variable

### Form

> **ax + b = 0** → **x = −b/a**

### Example 1

3x + 12 = 0 → x = −12/3 = **−4** ✅

### Example 2

5x − 7 = 2x + 8 → 3x = 15 → x = **5** ✅

### Word Problem Strategy

1. Let the unknown be x
2. Translate the English into an equation
3. Solve for x

**Example**: A number increased by 15 gives 42. Find the number.

x + 15 = 42 → x = **27** ✅

---

## CONCEPT 2: Linear Equations in 2 Variables

### Form

> **a₁x + b₁y = c₁**
> **a₂x + b₂y = c₂**

### Methods of Solving

**Method 1: Substitution** — Express one variable in terms of the other, substitute.

**Method 2: Elimination** — Multiply equations to make coefficients equal, then add/subtract.

**Method 3: Cross-Multiplication**

> x / (b₁c₂ − b₂c₁) = y / (c₁a₂ − c₂a₁) = 1 / (a₁b₂ − a₂b₁)

### Example (Elimination)

2x + 3y = 13 … (i)
5x − 2y = 4 … (ii)

(i)×2: 4x + 6y = 26
(ii)×3: 15x − 6y = 12

Adding: 19x = 38 → x = 2
From (i): 4 + 3y = 13 → y = 3

**x = 2, y = 3** ✅

### Conditions for Solutions

| Condition | Meaning | Graphically |
|---|---|---|
| a₁/a₂ ≠ b₁/b₂ | **Unique solution** (consistent) | Lines intersect |
| a₁/a₂ = b₁/b₂ = c₁/c₂ | **Infinite solutions** (dependent) | Lines overlap |
| a₁/a₂ = b₁/b₂ ≠ c₁/c₂ | **No solution** (inconsistent) | Lines are parallel |

### Example

2x + 3y = 5 and 4x + 6y = 10.
a₁/a₂ = 2/4 = 1/2. b₁/b₂ = 3/6 = 1/2. c₁/c₂ = 5/10 = 1/2.
All equal → **Infinite solutions** ✅

## CONCEPT 3: Quadratic Equations

### Standard Form

> **ax² + bx + c = 0** (where a ≠ 0)

### Finding Roots

**Method 1: Factorization (Splitting the Middle Term)**

Find two numbers whose:
- Product = a × c
- Sum = b

**Example**: x² + 5x + 6 = 0

Product = 1 × 6 = 6. Sum = 5. Numbers: 2 and 3.
x² + 2x + 3x + 6 = 0
x(x + 2) + 3(x + 2) = 0
(x + 2)(x + 3) = 0
x = **−2** or x = **−3** ✅

**Method 2: Quadratic Formula (Shreedharacharya's Formula)**

> **x = [−b ± √(b² − 4ac)] / 2a**

**Example**: 2x² − 7x + 3 = 0

a=2, b=−7, c=3
D = b² − 4ac = 49 − 24 = 25
x = (7 ± 5) / 4
x = 12/4 = 3 or x = 2/4 = 1/2

x = **3** or x = **1/2** ✅

---

## CONCEPT 4: Nature of Roots (Discriminant)

### The Discriminant

> **D = b² − 4ac**

| Value of D | Nature of Roots |
|---|---|
| D > 0 | **Two distinct real roots** |
| D = 0 | **Two equal (repeated) real roots** |
| D < 0 | **No real roots** (imaginary roots) |
| D is a perfect square (and a,b,c rational) | **Rational roots** |
| D > 0 but not a perfect square | **Irrational roots** (come in conjugate pairs: p+√q and p−√q) |

### Example 1

x² − 6x + 9 = 0. D = 36 − 36 = 0. → **Equal roots** (both = 3) ✅

### Example 2

x² + 3x + 5 = 0. D = 9 − 20 = −11 < 0. → **No real roots** ✅

### Example 3

2x² − 5x + 1 = 0. D = 25 − 8 = 17 > 0, not a perfect square → **Two irrational roots** ✅

### Key Property of Irrational Roots

> If one root is **p + √q**, the other root is **p − √q**.
> Irrational roots of a quadratic (with rational coefficients) always come in **conjugate pairs**.

Similarly, if one root is **p + iq** (imaginary), the other is **p − iq**.

## CONCEPT 5: Sum & Product of Roots (Vieta's Formulas)

### THE MOST TESTED CONCEPT

For ax² + bx + c = 0 with roots α and β:

> **Sum of roots: α + β = −b/a**
>
> **Product of roots: α × β = c/a**

### Example 1

3x² − 7x + 2 = 0.
Sum = 7/3. Product = 2/3. ✅

### Example 2

If roots of x² − 5x + k = 0 are in ratio 2:3, find k.

Let roots = 2a and 3a.
Sum: 2a + 3a = 5a = 5 → a = 1. Roots = 2, 3.
Product: 2 × 3 = k = **6** ✅

### Derived Relations (EXAM FAVOURITES)

| Expression | Formula |
|---|---|
| α² + β² | (α + β)² − 2αβ |
| α² − β² | (α + β)(α − β) |
| (α − β)² | (α + β)² − 4αβ |
| α³ + β³ | (α + β)³ − 3αβ(α + β) |
| α³ − β³ | (α − β)(α² + αβ + β²) |
| 1/α + 1/β | (α + β) / αβ |
| α/β + β/α | (α² + β²) / αβ = [(α+β)² − 2αβ] / αβ |

### Example 3

If α, β are roots of x² − 4x + 3 = 0, find α² + β².

α + β = 4, αβ = 3.
α² + β² = (α + β)² − 2αβ = 16 − 6 = **10** ✅

### Example 4

If α, β are roots of 2x² − 5x + 1 = 0, find 1/α + 1/β.

Sum = 5/2, Product = 1/2.
1/α + 1/β = (α + β)/αβ = (5/2)/(1/2) = **5** ✅

## CONCEPT 6: Formation of Quadratic Equations

### Given the roots, form the equation

> **x² − (sum of roots)x + (product of roots) = 0**
>
> **x² − (α + β)x + αβ = 0**

### Example 1

Form the equation whose roots are 3 and −5.

Sum = 3 + (−5) = −2. Product = 3 × (−5) = −15.
**x² + 2x − 15 = 0** ✅

### Example 2

Form the equation whose roots are (2 + √3) and (2 − √3).

Sum = 4. Product = (2)² − (√3)² = 4 − 3 = 1.
**x² − 4x + 1 = 0** ✅

### Transformation of Roots

| If roots of given equation are α, β | New equation has roots | Relation |
|---|---|---|
| α, β → kα, kβ | Replace x by x/k | Sum × k, Product × k² |
| α, β → α+k, β+k | Replace x by (x−k) | Sum + 2k, Product changes |
| α, β → 1/α, 1/β | Replace x by 1/x (then rearrange) | Reciprocal equation |
| α, β → α², β² | Sum = (α+β)²−2αβ, Product = (αβ)² | — |

## CONCEPT 7: Polynomials — Factor & Remainder Theorem

### Polynomial

> An expression of the form **aₙxⁿ + aₙ₋₁xⁿ⁻¹ + … + a₁x + a₀**
>
> Degree = highest power of x.

| Degree | Name | Example |
|---|---|---|
| 1 | Linear | 3x + 5 |
| 2 | Quadratic | x² + 3x + 2 |
| 3 | Cubic | x³ − 2x² + x − 1 |
| 4 | Quartic/Biquadratic | x⁴ + 2x² + 1 |

### Remainder Theorem

> When polynomial f(x) is divided by (x − a), the remainder is **f(a)**.

**Example**: f(x) = x³ − 3x² + 2x + 5. Remainder when divided by (x − 2)?

f(2) = 8 − 12 + 4 + 5 = **5** ✅

### Factor Theorem

> If f(a) = 0, then **(x − a) is a factor** of f(x).

**Example**: Is (x − 1) a factor of x³ − 3x² + 3x − 1?

f(1) = 1 − 3 + 3 − 1 = 0. Yes, **(x − 1) is a factor** ✅

In fact, x³ − 3x² + 3x − 1 = (x − 1)³.

## CONCEPT 8: Algebraic Identities (THE MOST IMPORTANT FOR EXAMS)

### The Must-Know Identities

**Two-Variable Identities:**

| # | Identity | Name |
|---|---|---|
| 1 | **(a + b)² = a² + 2ab + b²** | Square of sum |
| 2 | **(a − b)² = a² − 2ab + b²** | Square of difference |
| 3 | **a² − b² = (a + b)(a − b)** | Difference of squares |
| 4 | **(a + b)² + (a − b)² = 2(a² + b²)** | Sum of square expansions |
| 5 | **(a + b)² − (a − b)² = 4ab** | Difference of square expansions |

**Cube Identities:**

| # | Identity |
|---|---|
| 6 | **(a + b)³ = a³ + 3a²b + 3ab² + b³ = a³ + b³ + 3ab(a + b)** |
| 7 | **(a − b)³ = a³ − 3a²b + 3ab² − b³ = a³ − b³ − 3ab(a − b)** |
| 8 | **a³ + b³ = (a + b)(a² − ab + b²)** |
| 9 | **a³ − b³ = (a − b)(a² + ab + b²)** |

**Three-Variable Identities:**

| # | Identity |
|---|---|
| 10 | **(a + b + c)² = a² + b² + c² + 2(ab + bc + ca)** |
| 11 | **a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca)** |
| 12 | **If a + b + c = 0, then a³ + b³ + c³ = 3abc** |

### The KEY Relationships (Exam-Tested Repeatedly)

From (a + b)² = a² + 2ab + b²:
> **a² + b² = (a + b)² − 2ab**
> **a² + b² = (a − b)² + 2ab**
> **(a + b)² = (a − b)² + 4ab**
> **(a − b)² = (a + b)² − 4ab**

From (a + b + c)²:
> **a² + b² + c² = (a + b + c)² − 2(ab + bc + ca)**
> **ab + bc + ca = [(a + b + c)² − (a² + b² + c²)] / 2**

### Example 1

If x + 1/x = 5, find x² + 1/x².

(x + 1/x)² = x² + 2 + 1/x²
25 = x² + 1/x² + 2
x² + 1/x² = **23** ✅

### Example 2

If x − 1/x = 3, find x² + 1/x².

(x − 1/x)² = x² − 2 + 1/x²
9 = x² + 1/x² − 2
x² + 1/x² = **11** ✅

### Example 3

If x + 1/x = 5, find x³ + 1/x³.

x³ + 1/x³ = (x + 1/x)³ − 3(x + 1/x)
= 125 − 15 = **110** ✅

### Example 4

If a + b + c = 0, find (a³ + b³ + c³) / abc.

a³ + b³ + c³ = 3abc (since a+b+c = 0)
Answer = 3abc/abc = **3** ✅

## CONCEPT 9: The x + 1/x Family (EXAM FAVOURITE)

### The Chain

Given **x + 1/x = k**, you can find everything:

| Expression | Formula | Using k |
|---|---|---|
| x² + 1/x² | (x + 1/x)² − 2 | k² − 2 |
| x² − 1/x² | (x + 1/x)(x − 1/x) | — |
| x − 1/x | ±√(x² + 1/x² − 2) = ±√(k² − 4) | ±√(k² − 4) |
| x³ + 1/x³ | (x + 1/x)³ − 3(x + 1/x) | k³ − 3k |
| x³ − 1/x³ | (x − 1/x)³ + 3(x − 1/x) | — |
| x⁴ + 1/x⁴ | (x² + 1/x²)² − 2 | (k² − 2)² − 2 |

Given **x − 1/x = m**:

| Expression | Formula | Using m |
|---|---|---|
| x² + 1/x² | (x − 1/x)² + 2 | m² + 2 |
| x + 1/x | ±√(x² + 1/x² + 2) = ±√(m² + 4) | ±√(m² + 4) |
| x³ − 1/x³ | (x − 1/x)³ + 3(x − 1/x) | m³ + 3m |

### Example

x + 1/x = 4. Find x⁴ + 1/x⁴.

x² + 1/x² = 16 − 2 = 14.
x⁴ + 1/x⁴ = 14² − 2 = 196 − 2 = **194** ✅

## CONCEPT 10: Factorization

### Common Methods

| Method | When to Use | Example |
|---|---|---|
| **Common factor** | All terms share a factor | 6x² + 9x = 3x(2x + 3) |
| **Grouping** | 4 terms, group in pairs | ax + ay + bx + by = (a+b)(x+y) |
| **Identity: a²−b²** | Difference of two squares | x² − 49 = (x+7)(x−7) |
| **Splitting middle term** | Quadratic ax²+bx+c | x² + 5x + 6 = (x+2)(x+3) |
| **Identity: a³+b³ / a³−b³** | Sum/difference of cubes | 8x³ + 27 = (2x+3)(4x²−6x+9) |
| **Perfect square** | a²+2ab+b² or a²−2ab+b² | x² + 6x + 9 = (x+3)² |

### Example

Factorize: 2x² + 7x + 3

Product = 2 × 3 = 6. Sum = 7. Numbers: 6, 1.
2x² + 6x + x + 3 = 2x(x + 3) + 1(x + 3) = **(2x + 1)(x + 3)** ✅

## CONCEPT 11: Surds

### What is a Surd?

> A surd is an **irrational root** that cannot be simplified to a rational number.
> Examples: √2, √3, ∛5, √7

### Types

| Type | Example |
|---|---|
| Pure surd | √5, ∛7 |
| Mixed surd | 3√2, 5√3 |
| Compound surd | √2 + √3, 2 − √5 |
| Conjugate surds | (a + √b) and (a − √b) |

### Laws of Surds

| Law | Rule |
|---|---|
| √(ab) = √a × √b | Product under root |
| √(a/b) = √a / √b | Division under root |
| (√a)² = a | Square of root |
| ⁿ√(aᵐ) = a^(m/n) | Fractional exponent |
| ⁿ√a × ⁿ√b = ⁿ√(ab) | Same order roots |

### Rationalizing the Denominator

> **For monomial surds**: Multiply by √a/√a
>
> 1/√3 = 1/√3 × √3/√3 = **√3/3**

> **For binomial surds**: Multiply by the conjugate
>
> 1/(√3 + √2) = (√3 − √2) / [(√3)² − (√2)²] = **(√3 − √2) / 1 = √3 − √2**

### Example 1

Simplify: 1/(√5 − √3)

Multiply by conjugate: (√5 + √3)/(√5 + √3)
= (√5 + √3)/(5 − 3) = **(√5 + √3)/2** ✅

### Example 2

If x = (√5 + √3)/(√5 − √3), find x + 1/x.

x = (√5 + √3)²/(5 − 3) = (5 + 3 + 2√15)/2 = (8 + 2√15)/2 = 4 + √15
1/x = (√5 − √3)²/2 = (8 − 2√15)/2 = 4 − √15

x + 1/x = 4 + √15 + 4 − √15 = **8** ✅

### Comparison of Surds

To compare √a and ∛b: convert to the same root order.

√2 vs ∛3: LCM of orders (2, 3) = 6.
√2 = 2^(1/2) = 2^(3/6) = ⁶√8
∛3 = 3^(1/3) = 3^(2/6) = ⁶√9

Since 9 > 8, **∛3 > √2** ✅

# STEP 5 — SHORTCUT METHODS


---

## Shortcut 1: Quick Quadratic Root Check

If ax² + bx + c = 0, check simple values:
- f(0) = c → tells if 0 is a root
- f(1) = a + b + c → tells if 1 is a root
- f(−1) = a − b + c → tells if −1 is a root
- f(2) = 4a + 2b + c → tells if 2 is a root

---

## Shortcut 2: x + 1/x Chain — Memorize the Pattern

Given x + 1/x = k:
- x² + 1/x² = k² − 2
- x⁴ + 1/x⁴ = (k² − 2)² − 2
- x³ + 1/x³ = k³ − 3k

This chain solves 80% of identity-based exam questions.

---

## Shortcut 3: a³ + b³ + c³ Quick Check

**If a + b + c = 0 → a³ + b³ + c³ = 3abc** (INSTANT answer!)

This appears in at least 1 question per SSC paper.

---

## Shortcut 4: Sum & Product Without Finding Roots

Never find actual roots in sum/product questions. Just use:
- Sum = −b/a
- Product = c/a
- α² + β² = Sum² − 2×Product
- 1/α + 1/β = Sum/Product

---

## Shortcut 5: Quick Nature of Roots

| Check | Conclusion |
|---|---|
| b² > 4ac | Two real distinct roots |
| b² = 4ac | Equal roots |
| b² < 4ac | No real roots |
| b² − 4ac is a perfect square | Rational roots |

---

## Shortcut 6: Factorization of a²+b²

> **a² + b² = (a + b)² − 2ab = (a − b)² + 2ab**

Cannot be factored into real linear factors (unlike a² − b²). But this transformation is invaluable for identity problems.

# STEP 6 — CONFUSION ZONES


---

## Confusion 1: (a+b)² ≠ a² + b²

**WRONG**: (3+4)² = 3² + 4² = 9 + 16 = 25 ❌ (accidentally correct here!)
**RIGHT**: (3+4)² = 49. And 3² + 4² = 25. These are NOT the same.

(a+b)² = a² + **2ab** + b². The **2ab** term is critical!

---

## Confusion 2: Sum of Roots = −b/a, NOT b/a

> **α + β = −b/a** (negative of b/a)

Students forget the minus sign. If equation is x² − 5x + 6 = 0:
Sum = −(−5)/1 = **+5** (not −5).

---

## Confusion 3: Discriminant Sign vs Root Sign

D < 0 means **no real roots** — NOT that the roots are negative.
Roots can be real and negative even when D > 0.

---

## Confusion 4: Identity vs Equation

| Identity | Equation |
|---|---|
| True for ALL values | True for SPECIFIC values only |
| (a+b)² = a² + 2ab + b² | x² + 5x + 6 = 0 |
| No "solving" needed | Solve to find x |

---

## Confusion 5: a² + b² vs (a + b)²

| Expression | Value |
|---|---|
| a² + b² | Sum of individual squares |
| (a + b)² | a² + 2ab + b² (includes cross term) |
| Difference | (a+b)² − (a²+b²) = 2ab |

# STEP 7 — EXAMINER TRAP GUIDE


| # | Trap | Defense |
|---|---|---|
| 1 | **Sum of roots: forgetting the negative sign** | α + β = **−b/a** (minus!) |
| 2 | **(a+b)² expanded without 2ab** | Always write: a² + **2ab** + b² |
| 3 | **Using the wrong identity for cubes** | a³+b³ = (a+b)(a²**−**ab+b²). a³−b³ = (a−b)(a²**+**ab+b²). Note the signs! |
| 4 | **a + b + c = 0 not noticed** | ALWAYS check. If true → a³+b³+c³ = 3abc instantly |
| 5 | **Solving for actual roots when not needed** | Use sum/product formulas instead |
| 6 | **Wrong sign when rationalizing** | Conjugate of (a+√b) is (a−√b), not (−a+√b) |
| 7 | **Comparing surds without converting order** | Convert to same root order first |
| 8 | **Remainder theorem: f(−a) vs f(a)** | Dividing by (x+a) → remainder = f(**−a**) |
| 9 | **Confusing x+1/x with x−1/x formulas** | x+1/x uses −2; x−1/x uses +2 (for squaring) |

# STEP 11 — MEMORY TECHNIQUES


## Mnemonic 1: Sum of Roots

> **\"Sum = −b/a\"** — **\"S**um is **N**egative **b** over **a**\"**
>
> Remember: S.N.B.A. — \"**S**um, **N**egative, **b**, **a**\"

## Mnemonic 2: Discriminant Nature

> **\"Positive = 2 roots. Zero = 1 root. Negative = No real root.\"**
>
> \"P.Z.N\" — \"**P**air, **Z**ero (one), **N**one\"

## Mnemonic 3: Identities — Signs in Cube Formulas

> **a³ + b³ = (a+b)(a² − ab + b²)** — \"Plus outside, Minus inside\"
> **a³ − b³ = (a−b)(a² + ab + b²)** — \"Minus outside, Plus inside\"
>
> The sign of ab in the trinomial is OPPOSITE to the sign between cubes.

## Mnemonic 4: x + 1/x Chain

> **\"Square minus 2, Cube minus 3k\"**
>
> x² + 1/x² = k² − **2**
> x³ + 1/x³ = k³ − **3k**

## Story Trick: Why a+b+c=0 → cubes = 3abc

> Think of three friends A, B, C whose total contribution is zero (one owes what the others give).
> When you cube their contributions and add, you get exactly 3 times their mutual product.
> Balanced debts create perfect symmetry.

# STEP 14 — REVISION PACK


```
ALGEBRA — ONE-PAGE SUMMARY

LINEAR: ax + b = 0 → x = −b/a.
2-VAR: Elimination or Substitution. Check a₁/a₂ vs b₁/b₂ for solution type.

QUADRATIC: ax² + bx + c = 0.
  Roots: Factorize or x = (−b±√D)/2a.
  D = b²−4ac. D>0: 2 real. D=0: equal. D<0: no real.
  Sum = −b/a. Product = c/a.
  α²+β² = Sum²−2Product. 1/α+1/β = Sum/Product.
  Formation: x² − (sum)x + (product) = 0.

IDENTITIES:
  (a+b)² = a²+2ab+b². (a−b)² = a²−2ab+b².
  a²−b² = (a+b)(a−b).
  (a+b+c)² = a²+b²+c² + 2(ab+bc+ca).
  a³+b³ = (a+b)(a²−ab+b²). a³−b³ = (a−b)(a²+ab+b²).
  IF a+b+c = 0 → a³+b³+c³ = 3abc.

x + 1/x CHAIN (k = x+1/x):
  x²+1/x² = k²−2.  x³+1/x³ = k³−3k.  x⁴+1/x⁴ = (k²−2)²−2.

x − 1/x CHAIN (m = x−1/x):
  x²+1/x² = m²+2.  x³−1/x³ = m³+3m.

SURDS: Rationalize by multiplying with conjugate.
  1/(√a+√b) = (√a−√b)/(a−b).

REMAINDER THEOREM: f(x) ÷ (x−a) → Remainder = f(a).
FACTOR THEOREM: f(a) = 0 → (x−a) is a factor.
```

## 🚨 Trap Sheet

| Trap | Defense |
|---|---|
| Sum of roots = b/a | NO! Sum = **−b/a** (negative!) |
| (a+b)² = a²+b² | NO! Include **+2ab** |
| a³+b³ sign in trinomial | OPPOSITE: sum of cubes → minus ab; diff of cubes → plus ab |
| D < 0 means negative roots | NO! D < 0 means no REAL roots |
| x+1/x vs x−1/x formula mixed | +1/x: square **minus** 2. −1/x: square **plus** 2 |
| a+b+c=0 not checked | ALWAYS check before expanding cubes |
